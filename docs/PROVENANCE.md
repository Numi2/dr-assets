# Provenance

## Dr.Anmar content

Dr.Anmar Project Developers author and maintain the procedure-specific assets,
patient models, contact-driven effect code, interaction contracts, and
standalone repository integration.

This repository was separated from the Dr.Anmar product repository at source
commit `97973b2` so assets can evolve with a clear ownership, licensing, and
consumption boundary.

## ORBIT-Surgical-derived foundation

The Python compatibility namespace, extension skeleton, and base dVRK PSM/ECM
and STAR configurations descend from ORBIT-Surgical. Those files retain their
original copyright headers and BSD-3-Clause terms.

The namespace is a compatibility surface, not a claim that this repository is
an upstream ORBIT-Surgical release.

## NVIDIA foundations

NVIDIA Isaac Sim, Isaac Lab, PhysX, and Isaac for Healthcare provide simulation
runtime, solver, sensor, workflow, or catalog foundations used or targeted by
this work. They are external dependencies and remain owned by their respective
rightsholders.

References to NVIDIA products describe technical interoperability. Dr.Anmar
Assets is independently maintained and does not imply NVIDIA sponsorship,
certification, or endorsement.

## Asset-level notices

Asset families contain local `LICENSE.txt`, `NOTICE.txt`, manifests, and README
files. Those local notices are authoritative for the files in their directory.
Do not detach a USD entrypoint from its notices or dependency folder when
redistributing it.
